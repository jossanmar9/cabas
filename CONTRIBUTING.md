# Contribuir a Cabàs

El projecte està en fase inicial. Les propostes de documentació, accessibilitat i definició d’ús també són benvingudes.

1. Revisa el [roadmap](docs/ROADMAP.md) i les incidències del repositori.
2. Per a canvis amplis, obri una incidència amb el problema i el resultat esperat.
3. Treballa en una branca i envia una pull request amb el canvi i les comprovacions realitzades.

Utilitza preferentment el valencià en la documentació i els textos de la interfície. Mantín un tracte respectuós i aporta exemples reproduïbles.

## Criteris

- Respectar el funcionament offline i l’absència d’anuncis i telemetria.
- No incloure dades financeres personals, credencials ni claus de signatura.
- Mantindre els canvis acotats i actualitzar la documentació afectada.
- Documentar com s’ha verificat cada canvi. Els requisits de compilació i proves es definiran en inicialitzar Android.

Les contribucions s’incorporen sota AGPL-3.0-or-later. Comprova la procedència i compatibilitat de qualsevol recurs de tercers.
