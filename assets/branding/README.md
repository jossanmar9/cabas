# Identitat visual

[cabas-logo.png](cabas-logo.png) és el logo original aportat per l’usuari el 27 d’octubre de 2026, procedent de la conversa inicial de disseny. Es conserva sense modificacions.

Representa un cabàs amb una moneda i rebuts. S’utilitza en el README i dins de l’app. La icona adaptativa del llançador (`app/src/main/res/mipmap-*/ic_launcher_foreground.png`) es genera retallant la cistella del logo sobre el fons crema `#FCF7EC`, dins de la zona segura de 66 dp.

El recurs s’inclou sota la mateixa llicència AGPL-3.0-or-later del projecte. No s’hi adjunten fonts vectorials ni variants.
